01 / Audio Engineering

FND
Reverb

GitHub

Open-source modular reverb engine built on Feedback Delay Network (FDN) architecture, offering 21 unique spatial algorithms — from tight studio rooms to galaxy-scale decay. Inspired by Valhalla's VintageVerb and Room.

Written in C++17 with JUCE, targeting VST3 on Windows and macOS. Features deep modulation, integrated 3-band EQ, ducking & gating dynamics, resizable dark UI with cyan accents, and JSON preset management.
